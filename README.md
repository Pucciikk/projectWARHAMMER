# Warpbound

Фанатский мод по мотивам Warhammer 40k для Minecraft **1.21.1** на **Fabric**.
Дизайн механик: документ «Warhammer 40k мод: Хаос, верфь и варп». Прототип неба: `../warp-prototype/warp-sky.html`.

## Как запустить

1. Нужны **JDK 21** и **IntelliJ IDEA** (плагин Minecraft Development по желанию).
2. Открой папку `warpbound` в IDEA как Gradle-проект и дождись импорта (первый раз скачается Minecraft, это долго).
3. Запуск игры: задача `runClient` (или `./gradlew runClient` в терминале).
4. Датаген (переводы и прочие генерируемые файлы): `./gradlew runDatagen`.
5. Готовый мод: `./gradlew build`, файл появится в `build/libs/`.

Если сборка ругается на версии, возьми актуальные для 1.21.1 на https://fabricmc.net/develop/ и поправь `gradle.properties`.

## Что уже есть (v0.1)

- Данные Хаоса у игрока: порча, скверна (неснимаемый пол порчи), «разочарование», благосклонность четырёх богов, состояние возвышения. Сохраняются, переживают смерть, синхронизируются с клиентом.
- Корабль v0: отдельное измерение `warpbound:ship_interior`, у каждого корабля свой участок, временный корпус-мостик с окнами.
- Варп-переход: вход (6 с) → транзит (10 мин) → выход (6 с). Поле Геллера садится, сильнее в шторм; ниже 70% экипаж слышит шёпоты и набирает порчу; при 0% — аварийный выход.
- Небо варпа в окнах корабля — перенесённый шейдер из прототипа: кровавые облака, ветвистые молнии, плёнка Поля, тени демонов, эффект порчи.
- Отладочный HUD в левом верхнем углу.
- Дредноут: шагоход из 11 хитбоксов с разной бронёй (саркофаг и реактор — уязвимые места). ПКМ — сесть в саркофаг, W/S — газ с инерцией, Ctrl (спринт) — бег: ноги чаще и шире, корпус пошатывается, A/D — медленный поворот ног, мышь — поворот корпуса (до 70° от ног), Shift — выйти. Шаги трясут камеру, поднимают пыль и глухо бьют в землю. F3+B показывает все части (красные — уязвимые).

## Команды (нужны читы / права оператора)

```
/wb ship create [имя]      заложить корабль (пока сразу готов)
/wb ship enter             подняться на борт
/wb ship leave             высадиться (только на орбите)
/wb ship warp [секунды]    начать переход (по умолчанию 600 с)
/wb ship abort             аварийный выход
/wb ship field <0-100>     задать Поле Геллера
/wb ship storm <0-100>     задать шторм
/wb ship info

/wb chaos get
/wb chaos add <число>
/wb chaos set <corruption|taint|disappointment|khorne|nurgle|tzeentch|slaanesh> <0-100>
/wb chaos reset
```

```
/wb crashsite              поставить капсулу с обломками рядом с тобой (для тестов)
/wb quest reset            сбросить квесты и сюжетные флаги
/wb quest flag <флаг>      выставить сюжетный флаг (например beacon_repaired)

/warband create <имя>      создать отряд (без читов)
/warband invite <игрок>    пригласить
/warband accept            принять приглашение
/warband leave | info
```

Быстрая проверка: `/wb ship enter`, `/wb ship storm 80`, `/wb ship warp 60`, смотреть в нос корабля.

## Глава I: «Обломки»

Новый мир начинается у разбитой спасательной капсулы прямо у точки спавна (отключается
`crashSiteEnabled` в конфиге). Игрок приходит в себя рядом с ней, в чате звучит монолог.
В капсуле сундук с первым инфопланшетом и сломанный вокс-маяк, вокруг три кучи обломков
с остальными планшетами и вокс-модулем.

- Книга квестов: кнопка с аквилой над инвентарём или клавиша **J**.
- Вокс-маяк чинится вокс-модулем (крафт: редстоун, медь, железо) плюс 8 железа, 8 меди, 8 редстоуна.
- Награда за починку — «Знак Омниссии». ПКМ по маяку: с неба спускается техножрец.
  Shift+ПКМ: знак осквернён, варп-вспышкой приходит тёмный техножрец (+5 порчи).
- На второй день начинается лёгкий шёпот, и в книге появляется запечатанная вкладка Хаоса.

Квесты лежат в датапаке: `data/warpbound/quest_chapter/*.json` и `data/warpbound/quest/<глава>/*.json`
(позиция на карте, родители, условия `item` / `crafted` / `flag`, награды). Тексты на русском прямо в JSON,
`{player}` подставляет ник. Перезагрузка — `/reload`.

Текстуры интерфейса, предметов, блоков и техножрецов генерируются скриптами:
`python3 tools/textures/gen_ui.py` и `python3 tools/textures/gen_items.py` (нужен Pillow).

## Верфь (Сезон 1)

Пульт верфи ставится лицом к себе; док (13×43, высота 11) уходит **за** пульт. Раму из балок стапеля
подсвечивает ошибками удар Омниссианским ключом по пульту (ПКМ): жёлтым — чего не хватает, красным — лишнее.
Собранная верфь: ПКМ по пульту — экран постройки (сдать ресурсы → начать этап → через время часть корабля в доке).
После шести этапов — «Старт»: синий варп-огонь, док пустеет, корабль появляется в реестре. Shift+ПКМ ключом — разобрать.

```
/wb shipyard frame      поставить раму вокруг ближайшего пульта (для тестов)
/wb shipyard advance    закрыть поставки и закончить текущий этап (для тестов)
```

Шаблон рамы, класс «Фрегат» и части корабля генерирует `python3 tools/shipyard/gen.py`,
текстуры — `python3 tools/textures/gen_shipyard.py`. Автотесты: `./gradlew runGametest`.

## Первая индустрия и корабль (Сезон 1)

- **Горн обломков** — печь для корабельного лома: обшивка → пласталь, латунный пояс и медь → латунь,
  пластальная шихта (4 железа + медь + уголь) → пласталь, если лом кончился.
- **Ручной пресс** — слиток в руке, ПКМ несколько раз: пластины и шестерни. Shift+ПКМ пустой рукой — сменить штамп.
- После старта с верфи корабль на орбите родного мира; **телепорт-маяк** (выдаётся при старте) поднимает на борт.
- Интерьер фрегата собран из отсеков: корма с варп-двигателем, реактор, коридор, залы Поля Геллера, телепортариум,
  часовня, мостик с панорамным окном. Стены не ломаются; свои сундуки, верстаки, факелы ставить и убирать можно.
- **Навигационный стол** на мостике — выбор мира и прыжок (5 минут). **Телепортариум** — высадка на мир под кораблём.
- Квесты: глава «Киль» открывается после «Ответа» (техножрец приносит схему стапеля).

Генераторы: `python3 tools/ship/gen_interior.py` (отсеки и раскладка), `python3 tools/textures/gen_industry.py` (текстуры).

## Дредноут

Яйцо призыва во вкладке «Яйца призыва» или `/summon warpbound:dreadnought`.
Модель и текстура генерируются скриптом: `python3 tools/dreadnought/gen.py` (нужны Pillow и numpy).
Скрипт пишет `assets/warpbound/models/entity/dreadnought.json` и текстуры; игра читает модель из JSON
при каждой перезагрузке ресурсов. С флагом `--dev` скрипт копирует файлы и в `build/`, и в запущенной
игре достаточно нажать F3+T. Хитбоксы — в `DreadnoughtEntity`.

## Автотест в клиенте

```
./gradlew runAutotest -Pscenario=smoke
```

Клиент сам открывает (или создаёт) тестовый мир `wb_autotest` — творческий, мирный, вечный полдень, сид 20261201, —
выполняет сценарий `tools/autotest/<имя>.txt` и закрывается. Строки сценария: `wait <тики>`, `cmd <команда>`,
`look <yaw> <pitch>`, `hud on|off`, `clearchat`, `shot <имя>`, `log <текст>`, `quit`, `#` — комментарий (подробно — в `Autotest.java`).
Скриншоты — `run/screenshots/autotest/<сценарий>/`, лог (команды и весь чат) — `run/autotest/<сценарий>.log`.
Пока клиент работает, окно игры не трогать. В обычной игре автотест выключен.

## Настройки

`config/warpbound.json` создаётся при первом запуске: длительность перехода, расход Поля, частота шёпотов и т.д.
