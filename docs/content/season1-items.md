## Материалы

| Материал | Как получить |
|---|---|
| Свинцовый слиток | печь / плавильная печь из сырого свинца |
| Латунный слиток | горн обломков: медный слиток или латунная отделка |
| Пласталевый слиток | горн обломков: корабельный лом, обшивка, обгоревшая обшивка; долго — из пласталевой смеси |
| Пласталевая смесь | верстак (запасной путь к пластали) |
| Сырые свинец, радий, адамантий; осколок варп-камня; псайкристалл | добыча |

## Компоненты

| Компонент | Где | Рецепт |
|---|---|---|
| Пласталевая пластина | ручной пресс | пласталевый слиток, 4 нажатия |
| Латунная шестерня ×2 | ручной пресс | латунный слиток, 3 нажатия |
| Вокс-модуль | верстак / обломки | (глава 1) |
| **Фокусирующая линза** | верстак | аметист + стеклянная панель + латунный слиток |
| **Капаситор ×2** | верстак | 2 медных слитка, 2 редстоуна, свинцовый слиток |
| **Лазпакет ×2** | верстак | 2 свинцовых слитка + капаситор |
| **Разряженный лазпакет → лазпакет** | костёр | аварийная зарядка (30 с) |
| **Сервопривод** | верстак | 2 латунные шестерни, редстоун, 2 пласталевые пластины, железо |
| **Цепное полотно** | верстак | 4 пласталевые пластины + 2 цепи |
| **Флак-пластина ×2** | верстак | 2 шерсти + пласталевая пластина |
| **Фильтр респиратора ×2** | верстак | древесный уголь + бумага + шерсть |

## Оружие и броня

| Предмет | Рецепт | Как работает |
|---|---|---|
| **Лазган** | 2 пласталевые пластины, линза, капаситор, латунная шестерня, доски | ПКМ — луч на 48 блоков, урон и поджог; 30 выстрелов на лазпакет; Shift + ПКМ — перезарядка, пустой пакет остаётся |
| **Цепной меч** | 2 цепных полотна, сервопривод, 2 латунные шестерни | тяжёлый медленный клинок, брызги и визг цепи; чинится цепным полотном |
| **Флак-броня** (шлем, жилет, штаны, ботинки) | флак-пластины, формы как у ванильной брони | чуть крепче железной; чинится флак-пластиной |
| **Респиратор** | кожа, 2 фильтра, пласталевая пластина | слот шлема; на Кинерисе — дышать (с миром) |
| Колба для пробы ×2 | 3 стеклянные панели + железный самородок | варп-пробоотборник анклава |

## Корабельные блоки (добавлены рецепты)

Обшивка корабля ×4 — 4 пласталевые пластины; латунная отделка ×4 — 4 латунных слитка.
