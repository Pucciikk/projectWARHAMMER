# Каталог контента Warpbound: руды, материалы, предметы, блоки, сущности

Рабочий список от 26.10.2026: что вообще есть в моде и что для этого надо моделировать.
Основан на решениях из `docs/design-log.md`, `docs/season1.md`, `docs/industry/*.md`, `docs/systems/*.md` и каноне 40k.
Канон и символику легионов берём свободно (вопрос закрыт). Условие одно: логотип GW на загрузочном экране.

Это черновик: имена и ID можно менять. Цифры (урон, броня, время крафта) сюда не пишем, они будут в JSON.
Строки с пометкой «предложение» ещё не одобрены автором.

**Статусы:**
- ✅ — уже есть в коде (графика — заглушка из скриптов);
- **S1** — нужно к Сезону 1 (1 декабря 2026);
- S2 — следующий сезон (главы 2–4: Кузня, культисты, прометий);
- S3+ — позже (Кинерис полностью, генетика, улей, мир-кузница, финал).

**Тип модели** (что делает автор в Blockbench):
- **GL-сущ.** — анимированная сущность GeckoLib (`.geo.json` + `.animation.json` + текстура);
- **GL-блок** — блок с анимированной моделью (машина, дверь);
- **блок** — статичная JSON-модель блока (Blockbench → Java Block/Item);
- **3D-пр.** — предмет с 3D-моделью в руке (оружие, инструменты);
- **броня** — модель брони на игроке (GeckoLib armor);
- **2D** — плоская иконка 16×16, модель не нужна (делаю скриптом).

## 8. Технические требования к моделям автора

- **Формат:** Blockbench, «GeckoLib Animated Model» для сущностей, брони и анимированных блоков; «Java Block/Item» для статики.
  Исходник `.bbmodel` — в `art/<категория>/`, экспорт — в `assets/warpbound/geo|animations|textures/`.
- **GeckoLib ещё не подключён** (зависимость одобрена). Подключу, когда придёт первая модель.
- **Масштаб:** 16 пикселей модели = 1 блок. Рост — по таблицам выше (хитбокс подгоню под модель, но лучше сразу держать рост).
- **Текстуры:** одна плотность на модель. Сейчас у дредноута 1024×1024, у техножреца скин 64×64. Предложение: 32 px на блок
  для NPC-людей, у крупных — по необходимости. Светящиеся части (линзы, глаза, варп) — отдельной текстурой `_glow`, как у дредноута.
- **Скелет гуманоидов:** общие имена костей (`body`, `head`, `left_arm`, `right_arm`, `left_leg`, `right_leg`, `right_item`, `left_item`),
  тогда анимации переносятся между моделями. Навесное (механодендриты, рюкзак, плащ) — отдельными костями.
- **Анимации** — по возможности в Blockbench. Чего нет — делаю процедурно в коде, как у дредноута.
- **Варианты** (культисты, легионы) — одна геометрия, разные текстуры и скрываемые кости.
