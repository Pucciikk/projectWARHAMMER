# Warpbound — мод Warhammer 40k для Minecraft

Инструкции и контекст для Claude Code. Полный журнал решений с датами — `docs/design-log.md`
(читай его, когда нужна история или детали). Этот файл — выжимка, по которой можно работать сразу.

## Кто автор и как с ним работать

- Автор — Puccikk. Программирует на C++, C#, Python; Java и моддинг Minecraft для него новые.
  Объяснения — через аналогии с C#, но сейчас автор просит **меньше обучения, больше дела**: делать мод, разберём код вместе позже.
- Общение — **на русском**. Идентификаторы в коде — на английском, комментарии в коде — на русском.
- Автор быстро печатает: «6» посреди фразы — это запятая (не зажался Shift).
- Текстуры и структуры пока генерируются Python-скриптами (Pillow). Позже автор пришлёт свои 3D-модели (Blockbench) и структуры — тогда заменим заглушки.
- Крупные решения (цель, сюжет, новые зависимости) — обсуждать с автором. Мелочи — делать и сообщать.
- **Автор проекта — Puccikk.** Архитектура, сюжет и решения — его. Авторство Claude нигде не указывать:
  никаких `Co-Authored-By`, `Claude-Session`, «Generated with Claude Code» в коммитах и PR, никаких «выбрано Claude» в документах.
- **Git — только по прямой просьбе автора.** Без неё никаких commit, add, merge, push, rebase, reset, tag, удаления веток.
  Можно: status, log, diff, show, checkout для чтения. Файлы в рабочей папке править можно.
  Когда автор просит «закоммить и запушь», сначала показать, что уйдёт, потом отправить. Разрешение действует только на этот раз.

## Сборка и запуск

```
./gradlew build                 # jar в build/libs/
./gradlew runClient             # клиент (папка run/, в git не попадает)
./gradlew runServer             # сервер (нужен run/eula.txt с eula=true)
./gradlew runDatagen            # переводы → src/main/generated/
python3 tools/textures/gen_ui.py      # текстуры книги квестов, иконки, кнопка, планшет
python3 tools/textures/gen_items.py   # блоки и предметы главы 1
python3 tools/dreadnought/gen.py [--dev]  # модель и текстуры дредноута (Pillow + numpy)
python3 tools/shipyard/gen.py          # рама верфи, класс «Фрегат», части корабля (.nbt)
python3 tools/textures/gen_shipyard.py  # текстуры верфи и ключа
python3 tools/ship/gen_interior.py      # отсеки фрегата (.nbt) и раскладка интерьера
python3 tools/textures/gen_industry.py  # текстуры горна, пресса, деталей и оборудования корабля
python3 tools/models/gen_entities.py    # заглушки моделей GeckoLib М1–М9 (geo, анимации, текстуры, _glow)
python3 tools/models/shuttle.py         # имперский челнок и десантная капсула (транспорт лоялистов)
python3 tools/models/warp_rift.py       # ритуальный знак и столб синего пламени (призыв тёмного техножреца)
python3 tools/models/gen_blocks.py      # модели машин и оборудования корабля (блоки из деталей, 32 px на блок)
python3 tools/models/gen_machines.py    # цельные модели собранных машин и крупного оборудования корабля (GeckoLib)
python3 tools/blocks/gen_block_set.py   # набор блоков (обшивка, руды, Кинерис, отсеки): текстуры, модели, лут, рецепты, теги, Java-регистрация
python3 tools/shipyard/gen.py           # стапель, фрегат и лёгкий крейсер (крейсер — tools/shipyard/dauntless.py из STL автора)
python3 tools/ship/gen_cruiser_interior.py  # 10 отсеков крейсера и раскладка light_cruiser
python3 tools/textures/gen_console_gui.py   # фон экрана командного пульта
python3 tools/textures/gen_star_map.py      # карта Империума (экран и табло на мостике)
python3 tools/textures/gen_s1_items.py      # предметы Сезона 1: лазган, цепной меч, флак, респиратор, компоненты (иконки и слои брони)
python3 tools/recipes/gen_s1_recipes.py     # рецепты предметов Сезона 1 (список — docs/content/season1-items.md)
python3 tools/models/gen_gear.py            # 3D-снаряжение GeckoLib: лазган, цепной меч, флак-броня гвардейца, респиратор
./gradlew runGametest                 # автотесты без игрока (верфь и т. д.)
./gradlew runAutotest -Pscenario=smoke  # клиент сам проходит tools/autotest/smoke.txt, скриншоты в run/screenshots/autotest/
./gradlew runAutotest -Pscenario=arrival   # прибытие операторов: челнок, капсула, ритуал
./gradlew runAutotest -Pscenario=cruiser   # крейсер на верфи; interior — отсеки и экран пульта; multiblocks — горн, пресс, Кузня
./gradlew runAutotest -Pscenario=launch    # крейсер: мостик, выход в космос, подготовка и разлом; bridge_ext — башня мостика снаружи
./gradlew runAutotest -Pscenario=sampler   # варп-пробоотборник анклава: цикл руки по кадрам; visit — построить крейсер и отдать управление автору
./gradlew runAutotest -Pscenario=gallery   # витрина предметов Сезона 1, гвардейцы во флаке, выстрел лазгана

./gradlew runAutotest -Pscenario=models    # галерея сущностей; machines — галерея машин. Скрины для автора — в previews/ (не в git)
```

Если Maven Central отвечает 429 — повторить с `--max-workers=1`.
Отладочные команды — в `README.md` (`/wb ship …`, `/wb chaos …`, `/wb crashsite`, `/wb quest reset|flag`, `/warband …`).

## Ключевые решения (и почему)

Подробно — `docs/design-log.md`. Главное:

- **Без долгих пеших походов по Overworld:** многим игрокам в окружении автора это не нравится. Находки в мире ускоряют и удешевляют, но не блокируют прогресс.
- **Варп-прыжки — часто** (не каждые 5 минут, но и не раз в игровой месяц): события перехода не стопроцентные, игроки должны их прочувствовать. Давать поводы прыгать.
- **Беречь сервер:** не держать много чанков загруженными; удалённое производство считать абстрактно.
- **Качество прежде всего, никакой «топорности»:** хитбокс = модель, вес и инерция у техники, шаги синхронны со скоростью, интерполяция по partialTick, ощущения через камеру/звук/частицы.
- **Сначала каркас, потом контент.** Цифры (урон, броня, баланс) — в JSON, не в коде. Датаген с самого начала.
- **Сюжет из 8 глав:** Обломки → Неизвестный мир → Кровь и сталь → Киль → Вслепую → Путеводная звезда → Наследие → Финал.
  Игрок — Вольный торговец, варп-шторм (его вызвал демон) стёр ему имя. Имя = ник игрока («Теперь я <ник>»).
  Империум возвращает имя и Патент, изгоняя демона; Хаос принимает сделку демона (путь к демон-принцу).
- **Overworld — неизвестный мир.** Империуму до него нет дела; лоялисты прилетают только по маякам игрока. Ванильные деревни не трогаем.
  В мире ~10 своих структур — обломки кораблей (3 хаоситских).
- **Глава 2:** техножрец ничего не строит сам — просит рабочее место; игрок строит мультиблочную Кузню 5×5×6, и **наградой за Кузню** выдаётся Знак Омниссии.
- **Генетика:** человек → Громовой воин (конец гл.5, сильный, но копит нестабильность) → неофит (гл.6) → Астартес (гл.7).
  Геносемя 18 легионов игрок создаёт сам по рецептам из гробницы Громового воина; предательское = лоялистская пара + ритуал осквернения.
  Семя меняется в любой момент (дорого, временные дебаффы). Глубина — полная: чаны, трубы, растворы, мини-игры.
  Экран «Генокарта» (своя модель на просвет + схема-чертёж, 19 органов, каждый — заметная способность; рост модели через атрибут scale)
  и Операция на ложе апотекариона. Хаос — случайные дары богов вместо органов.
- **Материалы из лора:** пласталь → керамит → адамантий (только на других мирах) → аурамит; ферробетон, армаплас; прометий (добыча как нефть: залежь → качалка → перегонная колонна), плазменные ячейки, радий; священное масло, ладан, ноктилит (глушит варп); варп-камень, демоническая сталь, латунь Кхорна.
- **Канон и символика — вопрос закрыт (26.10.2026), больше не поднимать.** Берём из канона 40k всё, что нужно:
  легионы, их символику, имена, технику. Единственное условие — **логотип GW на загрузочном экране мода**
  (логотип пришлёт автор; показать при загрузке ресурсов мода).
- **Легионы и ордена — каноничные, и доспех каждого отличается формой, а не только цветом:** например, у
  Повелителей Ночи — перепончатые крылья на шлеме, у Гвардии Смерти — наросты, отростки и рога на броне
  (решение 25.10.2026).
- **Контракт моделей** (имена файлов, костей и анимаций, чтобы модель автора заменила заглушку) — `docs/content/models.md`.
- **Каталог контента** (руды, материалы, предметы, блоки, сущности, порядок моделей для автора) — `docs/content/catalog.md`.
  Крафты, статы, урон, лут — по-прежнему позже, в JSON.

## Известные проблемы и долги

1. **Знак Омниссии сейчас выдаётся за починку маяка**, а по новому решению — за постройку Кузни (гл.2). Поменять награду квеста `voice_in_the_void` при реализации главы 2.
2. Текст квеста `fire_and_stone` называет мир «диким» — по новому решению мир «неизвестный». Сверить тексты главы 1.
3. Шёпот Хаоса считается по общему времени мира (`StoryDirector.WHISPER_DAY`), а не от первого входа игрока: в мультиплеере поздно зашедший игрок услышит шёпот сразу.
4. Техножрец без настоящего шаттла — просто спускается в дыму. Шаттл — позже.
5. Квест `voice_in_the_void` засчитывается, только когда выполнены родительские квесты, даже если маяк уже починен (так задумано, но может удивить при тестах через `/give`).
6. Вся графика — заглушки, сгенерированные скриптами; ждём модели автора. Дома у автора уже готовы модели 18 легионов
   и новая модель/текстура дредноута — в репозиторий ещё не попали (26.10.2026).

## Стиль кода и договорённости

- Код как в окружающих файлах: `final class` + статические `register()`/`init()` на систему, регистрация в `Warpbound.onInitialize`.
- Данные, которые правит дизайнер (квесты, главы, позже оружие/броня), — в JSON-реестрах через `DataRegistry` + Codec; плохая запись логируется, а не роняет игру.
- Состояние игрока — Data Attachments (persistent, copyOnDeath), синхронизация — свои пакеты в `network/`.

- Переводы — через датаген (`WarpboundDataGenerator`), ru и en; тексты квестов — по-русски прямо в JSON.
